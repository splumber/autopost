# Background music

No audio files are bundled here (avoids shipping anything with unclear
licensing). Drop your own royalty-free or properly licensed `.mp3` files in
this folder and the pipeline will pick one at random for each video.

Good free sources with clear commercial-use licenses:
- YouTube Audio Library (audio.youtube.com) -- filter by "no attribution required"
- Pixabay Music (pixabay.com/music) -- free license, commercial use allowed

With this folder empty, videos still render fine -- narration-only, no
background music.
