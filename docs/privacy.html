Privacy Policy

Last updated: 2026-09-17

"Autopost Content Studio" runs entirely on infrastructure controlled by its owner. It is not a multi-tenant service and does not collect data from, or about, anyone other than its owner's own linked TikTok account.

Data accessed

  • TikTok account data: open ID, display name, follower count, and video statistics for the single linked account, retrieved via TikTok's official API using an OAuth token the owner grants directly.
  • OAuth tokens: stored encrypted at rest, only on the owner's own machine/server, never transmitted anywhere except to TikTok's API.

Data sharing

No data is sold, shared, or transmitted to any third party. The only external services contacted are TikTok's own API, and (for sourcing background video clips) stock-footage providers' public APIs, using keyword search terms only -- no personal data is sent to those providers.

Data retention and deletion

All data is stored locally by the app owner and can be deleted at any time by deleting the local application data. Revoking the app's access from within the TikTok app immediately invalidates its ability to act on the account.

Contact

Questions about this policy can be raised via the project's GitHub repository issue tracker.
